# Arduino 和 Kotlin Compose：红外遥控信号分析与安卓红外遥控器应用开发文档

## **项目概述**

本项目通过 `Arduino Uno R3` 开发板及红外接收模块 `VS1838`，捕获电视机顶盒`新魔百和 M301H` 配套遥控器的红外信号，解析其协议与数据，并基于 `Android` 系统，通过 `Kotlin Compose` 编程语言，开发了一个红外遥控应用 `IRMaster`，实现了手机控制机顶盒的功能。

**核心流程**：

1. **信号捕获**：使用 Arduino 硬件捕获原始红外信号并解析协议。
2. **数据转换**：将解析后的信号数据转换为 Android 可发射的 NEC 协议格式。
3. **安卓应用**：通过手机红外发射器模拟遥控器信号，支持多按键功能。

## **硬件配置**

### 1. Arduino 红外接收模块

- **硬件清单**：

  - Arduino UNO R3 开发板
  - 红外接收传感器 VS1838B，接 PIN 11

- **接线说明**：

  - 传感器 `VCC` → Arduino `5V`
  - 传感器 `GND` → Arduino `GND`
  - 传感器 `OUT` → Arduino `D11`

### 2. Android 设备

- **要求**：设备需支持红外发射功能。

## **软件实现**

### 1. Arduino 信号捕获

**功能**：接收并解码红外信号，输出原始数据及协议信息。只需将遥控器对准红外接收模块，按下遥控器按键，Arduino 会输出相应的红外信号数据，即可记录相应按钮对应的红外信号数据。

**输出示例**：

```bash
31CEDD22
Protocol=NEC Address=0x22 Command=0xCE Raw-Data=0x31CEDD22 32 bits LSB first
Send with: IrSender.sendNEC(0x22, 0xCE, <numberOfRepeats>);
```

### 2. Android 应用

**功能模块**：

- **红外支持检测**：启动时检查设备是否支持红外功能。
- **遥控界面**：仿实物遥控布局，包含若干功能按钮。
- **信号发射**：将预定义的十六进制数据转换为 NEC 协议波形并发送。
- **触觉反馈**：按钮点击时触发短震动。
